Oracle Japan 技術情報

Oracle Cloud Infrastructure (OCI) を学び、活用するための学習資料と技術資料をご案内する技術情報リンク集です。

  • OCIチュートリアル

    画面ショットを交えた手順に沿って、実際にOCIを操作しながら学ぶチュートリアルサイトです。基本操作から各サービスの活用まで、段階的に学習できます。

  • OCI活用資料集

    OCIのサービス解説や設計、運用に関する技術資料をまとめています。セミナーなどで使用したスライドや動画を参照できます。

  • OCI公式ドキュメント

    OCIの各サービスの機能、設定方法、利用条件を確認できる公式マニュアルです。

  • Oracle Architecture Center

    用途に応じたシステム構成例と、設計上の推奨事項や実装手順を紹介しています。複数のサービスを組み合わせた構成検討の参考になります。

  • Oracle Quick Start（GitHub）

    OCI上の環境構築やソフトウェアの導入を自動化するコードを公開しています。Terraformなどによる構築例や、サンプルアプリケーションを参照できます。

  • オラクルエンジニア通信

    OCIやOracle Databaseをはじめとするオラクル製品の技術ブログです。新機能の解説、活用方法、イベントやセミナーの情報を発信しています。

  • OCIリリースノート

    OCIの新サービスや新機能、機能改善などの更新情報を掲載しています。サービスごとの変更内容とリリース日を確認できます。

  • Oracle LiveLabs

    オラクル製品を実際に操作して学べるハンズオン教材です。関心のある製品やテーマに応じて、実習形式のワークショップを探せます。言語は英語のみになりますのでご注意ください。

  • OCI Cloud Adoption Framework

    OCIの導入計画や組織体制、ガバナンス、運用の整備に関する指針です。クラウド導入を進める際の検討事項を確認することができます。
